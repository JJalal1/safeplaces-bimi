The source TTF files were converted to WOFF2 locally using fontTools 4.61.1
and the installed Node.js Brotli codec. No glyph subsetting was performed.
All source Unicode mappings, glyph order, horizontal metrics, and GSUB/GPOS/
GDEF layout tables were compared after WOFF2 decoding and preserved.
Both Arabic and Latin source coverage are included. No third-party font
service is contacted when the website displays these fonts.
