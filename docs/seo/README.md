# خطة SEO للمناطق الآمنة

تاريخ المراجعة: 22 أكتوبر 2026. النطاق: https://safeplaces.sa

تم نشر صفحة طلبات المشاريع في المنطقة الشرقية بالعربية والإنجليزية، وتحديث عنوان ووصف الرئيسية، وتخصيص عناوين الخدمات بحسب نوع العمل. الصفحة الإقليمية توضح أن الموقع المعلن في الخبر وأن طلبات الدمام والظهران وبقية المدن تحتاج مراجعة نطاق التنفيذ. لا تدّعي وجود فروع إضافية.

خريطة الموقع تشمل 66 رابطًا عامًا باللغتين، ومنها الصفحات القانونية ودليل الشرقية، مع بدائل `ar` و`en` و`x-default`. صفحات الحساب والإدارة والفلاتر مستبعدة من الفهرسة. يسمح robots.txt بقراءة صفحات الاستعلام حتى يستطيع Google رؤية noindex والرابط الأساسي. تصحيح بيانات BreadcrumbList يصل إلى المنتج أو الخدمة نفسها، وربط Organization وWebSite وService بمعرّف مؤسسة موحّد. بيانات المنتجات لا تختلق أسعارًا أو توافرًا أو تقييمات.

اجتاز الإصدار `bfdec4067bf2650ea2849c697c358e98fd15867e` التحقق البرمجي واختبارات الحسابات والطلبات، وفحص 66 رابطًا في نسخة معزولة وفحص الروابط الـ66 نفسها بعد النشر. تقرير المتصفح يحوي 112 فحص عرض دون أخطاء JavaScript أو أصول مطلوبة. فحص 22 صفحة حية أكد بقاء بيانات المنشأة المنشورة، وقُبل اختبار الرسائل لدى مزود البريد. الأدلة في [تشغيل النشر](https://github.com/JJalal1/safeplaces-bimi/actions/runs/39842739832).

## خطة الكلمات

- `safeplaces-seo-plan.html`: تقرير عربي قابل للبحث والتصفية، يحتوي خطوات صاحب الموقع و510 عبارات مقترحة ضمن 21 مجموعة.
- `keyword-plan.json`: البيانات مع اللغة والنية والمدينة والرابط المناسب والأولوية التحريرية.
- `build-keyword-plan.mjs`: يعيد إنشاء الملفين بالأمر `node docs/seo/build-keyword-plan.mjs`.

جميع روابط الكلمات الـ45 المختلفة موجودة ضمن خريطة الموقع المختبرة. الخطة تجمع مفردات الكتالوج الفعلي، وعينات من المفردات السوقية، ومرادفات وأسئلة مقترحة. ليست تقريرًا من Keyword Planner أو Search Console؛ حجم البحث غير مقاس (`null`) ولا توجد تقديرات مختلقة للصعوبة أو الترتيب. ليست جميع العبارات منشورة حرفيًا، ولا تستخدم القائمة كحشو كلمات أو لإنشاء صفحات مدن مكررة.

## ما ينفذه المالك

1. فتح [Google Search Console](https://search.google.com/search-console) والتحقق من ملكية النطاق `safeplaces.sa` للحساب الصحيح. فحص DNS وجد سجل تحقق Google واحدًا؛ هذا لا يثبت اكتمال التوثيق داخل حساب المستخدم. لا تحذف سجل التحقق الحالي.
2. إرسال https://safeplaces.sa/sitemap.xml والتأكد من نجاح القراءة، ثم فحص الرئيسية ودليل الشرقية والخدمات المهمة وطلب الفهرسة عند الحاجة.
3. مراجعة تقارير فهرسة الصفحات والأمان والإجراءات اليدوية. حالات استبعاد الحسابات والفلاتر مقصودة، أما فشل الزحف لصفحات عامة فيحتاج متابعة.
4. توثيق ملف النشاط التجاري المؤهل على Google بالاسم الحقيقي والموقع الفعلي والهاتف والساعات والصور. لا تضف فروعًا أو مواقع غير حقيقية.
5. متابعة الأداء الفعلي وطلبات الأسعار بعد تراكم البيانات. يمكن استكمال حجم البحث من Keyword Planner باستهداف السعودية أو الشرقية. GA4 اختياري لقياس الاستخدام والتحويلات ويحتاج معرّف حساب حقيقي وإعداد الخصوصية المناسب؛ لا يوجد معرّف أو تتبع مختلق.

الفهرسة والترتيب بقرار Google. اجتياز الاختبارات وإرسال الخريطة لا يضمنان فهرسة كل صفحة أو مرتبة معينة. لم تُفتح لوحة Search Console الخاصة بالمالك أو حساب النشاط التجاري، ولا يمكن تقرير حالتهما من DNS وحده. لم تتضمن هذه الجولة قياس بيانات Core Web Vitals الميدانية لدى زوار حقيقيين؛ تراجع في Search Console بعد توافر العينة.
